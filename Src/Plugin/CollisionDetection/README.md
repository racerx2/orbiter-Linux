# CollisionDetection

The add-on behind the **Collision detection** and **Reentry breakup** sections of the
[top-level README](../../../README.md): vessel-to-vessel contact against the actual mesh triangles,
and the same damage model driven by the air on entry.

One Orbiter module, enabled from the Launchpad's **Modules** tab. No vessel, mesh or add-on file is
modified and nothing in the Orbiter core changes.

**The source is not published yet.** This folder is a placeholder until it is. Come talk about it on
[Discord](https://discord.gg/fnxQYTKPFK).
